# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project is an end-to-end **Customer Shopping Behavior Analysis** project that focuses on understanding customer purchasing patterns, spending behavior, discounts, subscriptions, product performance, and customer segments.

The project follows a complete data analytics workflow:

**Python → Data Cleaning & EDA → SQL Server → Power BI → Report → Presentation**

The objective is to convert raw customer shopping data into **meaningful business insights** that can help understand customer behavior and improve business decision-making.

---

## 🎯 Business Objectives

The analysis focuses on answering key business questions such as:

* Which gender generates more revenue?
* Do customers using discounts still make high-value purchases?
* Which products have the highest average ratings?
* How does shipping type affect average purchase value?
* Do subscribed customers spend more than non-subscribers?
* Which products have the highest discount usage?
* How can customers be segmented based on previous purchases?
* What are the top products within each category?
* Are repeat buyers more likely to subscribe?
* Which age groups contribute the most revenue?

---

## 📂 Dataset

The project uses a **Customer Shopping Behavior dataset** containing customer-level purchase information.

Key fields include:

* Customer ID

* Category

## 🔄 Project Workflow

### 1. Data Loading

The raw customer shopping dataset was loaded into Python using **Pandas**.

Initial checks were performed to understand the dataset structure, columns, data types, and overall data quality.

### 2. Exploratory Data Analysis (EDA)

EDA was performed to identify:

* Missing values
* Duplicate records
* Data types
* Distribution of numerical variables
* Customer purchasing patterns
* Product and category trends
* Relationship between different customer attributes

### 3. Data Cleaning

The dataset was cleaned and prepared for analysis by:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing categorical values
* Creating relevant analytical columns such as **Age Group**
* Preparing the final cleaned dataset for SQL Server

The final cleaned table used for analysis was:

`cleaned_customer_shopping_data`

---

## 🧮 SQL Analysis

The cleaned dataset was imported into **SQL Server** and analyzed using SQL queries.

### Key Analysis Performed

**1. Revenue by Gender**

Compared total revenue generated by male and female customers.

**2. Discount & High-Value Purchases**

Identified customers who used discounts but still spent above the average purchase amount.

**3. Product Ratings**

Found the top 5 products with the highest average review ratings.

**4. Shipping Analysis**

Compared average purchase amounts between **Express** and **Standard** shipping.

**5. Subscription Analysis**

Compared subscribers and non-subscribers based on:

* Number of customers
* Average spend
* Total revenue

**6. Discount Analysis**

Identified the top 5 products with the highest percentage of purchases where discounts were applied.

**7. Customer Segmentation**

Customers were segmented into:

* New
* Returning
* Loyal

based on their previous purchase history.

**8. Product Performance**

Identified the top 3 most purchased products within each category using **Window Functions**.

**9. Repeat Buyer Subscription Analysis**

Analyzed whether customers with more than 5 previous purchases were more likely to subscribe.

**10. Revenue by Age Group**

Analyzed the revenue contribution of different age groups.
